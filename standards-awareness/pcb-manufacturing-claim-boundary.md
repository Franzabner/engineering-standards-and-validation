# PCB Manufacturing Claim Boundary

Status: scaffolded
Publication state: public scaffold
Release state: not released

## Purpose

This boundary separates public PCB review discipline from manufacturing approval, certification, or production-board authority.

## Allowed Claims

Allowed public claims:

- a checklist is scaffolded;
- a report template exists;
- examples are synthetic;
- sealed-board boundaries are documented;
- human review is required for any stronger claim.

## Forbidden Claims

Do not claim PCB manufacturing approval, KiCad production board review, sign-off, certification, stamped engineering, code compliance, customer approval, production readiness, deployment, or proof completion.

Do not include production board source, production schematics, KiCad source, Gerbers, BOMs, exact pin maps, manufacturing instructions, private firmware, customer wiring, or customer data.

## Review Result

If a PCB note implies approval or production use, rewrite it as a boundary question or hold it for private review.

# Human Review Gate Template

Status: scaffolded
Publication state: public scaffold
Release state: not released

## Purpose

This template records whether a public technical artifact remains inside scaffolded, public-safe boundaries.

## Review Record

| Field | Entry rule |
| --- | --- |
| Artifact name | Use the public artifact name only. |
| Status | planned, scaffolded, public scaffold, or not released. |
| Boundary class | public, private, sealed, or mixed. |
| Safe material | Name public-safe taxonomy, template, or review structure. |
| Held material | Name excluded categories, not private details. |
| Reviewer decision | public-safe, rewrite required, hold private, or escalation. |

## Claim Checks

Confirm the artifact does not claim live automation, production workflow, active agent workforce, PCB manufacturing approval, KiCad production board review, benchmark results, measured results, proof completion, energy output, proven output, deployment, production readiness, certification, safety approval, customer outcome, or external release activity.

## Evidence Rule

This review gate is not an approval, sign-off, certification, legal review, safety approval, or release authorization. It is a documentation control used before human review.

# Public Boundary

## Public-Safe Content

- Synthetic standards-awareness notes.
- Non-certified safety review checklists.
- Synthetic commissioning and test procedure templates.
- Risk register, failure-mode, acceptance criteria, and validation report templates.
- Mermaid validation review flow diagrams.

## Private / Sealed / Held Content

This repo must not contain certification claims, code-compliance approval claims, stamped-engineering implications, legal approval, customer procedures, private incident reports, production procedures, live commissioning records, customer data, Foundation-private data, secrets, credentials, private URLs, sealed source, private logs, active client deliverables, or internal company product names.

## Review Rule

Any move from local scaffold to public GitHub repo requires human review, validator pass, boundary/status scan, clean `git diff --check`, clean `git status --short`, and separate approval for routing.
